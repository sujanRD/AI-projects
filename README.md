# AI Chatbot using Python and Groq API

A simple AI chatbot built using Python, Jupyter Notebook, and the Groq API.

## Features

- Interactive chatbot
- Maintains conversation history
- Uses Groq API
- API key protected using environment variables
- Built completely with Python

## Technologies Used

- Python
- Jupyter Notebook
- Groq API
- python-dotenv

## How to Run

1. Clone this repository.
2. Install the required packages:

```bash
pip install groq python-dotenv
